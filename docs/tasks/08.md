Follow AGENTS.md. Input: 07_bt.parquet (surviving concepts, all splits), Unihan
Readings (kVietnamese) + Variants, CC-CEDICT. Output: 08_etym.parquet.

Use the canonical vi form's homograph entries whose vi_pos == the concept's pos
(if none match, use all; record entry_scope). All reading comparisons use
vi_orth_key.

Config:
  etymology:
    sinitic_codes: [zh, cmn, ltc, och, lzh, lzh-lit, yue, hak, wuu, cdo, gan, hsn]
    sinitic_prefixes: ["zh-", "nan"]
    sino_japanese_codes: [ja, ko]   # Sino only if args["3"] contains CJK
    loan_templates: [bor, bor+, lbor, obor, der, der+]
    calque_templates: [cal, calque]
    native_markers_text: [Proto-Vietic, Proto-Mon-Khmer, Proto-Austroasiatic]
    native_templates: [inh, inh+]
    gloss_overlap_min: 1

SIGNAL A (Wiktionary's claim), per concept:
  sino if ANY in-scope entry has: a vi-etym-sino template; OR a "Sino-Vietnamese
    words" category; OR a loan/calque template whose source is Sinitic; OR a
    loan template from ja/ko whose args["3"] contains CJK (record sino_via ∈
    {chinese, japanese_kango, calque, template}).
  other_loan if not sino AND some loan template has a non-Sinitic source whose
    code does NOT end in "-pro" (Tai, Sanskrit, …; European sources were already
    removed in step 06).
  nonsino otherwise (including words with no etymology at all).
  conflict: if in-scope homograph entries disagree (one sino, one not) → A = conflict.
  native_strict (flag, nonsino only): etymology text contains a native marker, OR
    a native template is present, OR a der/inh from a code ending in "-pro".

SIGNAL B (external verification of a Han spelling):
  Han strings = the CJK args of vi-etym-sino templates ∪ CJK `forms` of in-scope
  entries (dedupe; split on "/" and whitespace; keep only strings whose length ==
  the canonical form's syllable count).
  A Han string VERIFIES if all three hold:
   (1) reading: each character i has a kVietnamese reading whose vi_orth_key ==
       syllable i (also try the character's traditional/simplified variants via
       Unihan kTraditionalVariant/kSimplifiedVariant);
   (2) word: the string (as is, or converted t2s/s2t with OpenCC) is a CC-CEDICT
       headword (traditional or simplified column);
   (3) meaning: CEDICT glosses and (en_lemma + sense_gloss) share ≥ gloss_overlap_min
       content lemmas (spaCy en_core_web_sm, lowercase, stopwords removed).
  B = sino if any Han string verifies; else nonsino.
  Also record B_relaxed (checks 1 and 2 only) and, for failures, the first failing
  check (no_han_string | reading | not_in_cedict | meaning).

STRATUM:
  sino       if A == sino and B == sino
  nonsino    if A == nonsino and B == nonsino
  other_loan if A == other_loan
  ambiguous  otherwise (incl. A == conflict)
Cohen's κ between A and B over rows with A ∈ {sino, nonsino} (also report κ with
B_relaxed). Bootstrap a 95% CI for κ (1,000 resamples over concepts, seeded).
